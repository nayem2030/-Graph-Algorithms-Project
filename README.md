# Graph Algorithms in C

A C-based graph project implementing three fundamental graph algorithms: **Dijkstra's, Kruskal's, and Prim's Algorithm**.

## Features
- Graph representation using an Adjacency Matrix and Edge List.
- Shortest path calculation using Dijkstra's Algorithm.
- Minimum Spanning Tree using Kruskal's Algorithm.
- Minimum Spanning Tree using Prim's Algorithm.
- BFS for path reconstruction.
- Edge removal and before-after result comparison.
- File input using `input.txt`.

## Technologies
- Language: C
- Data Structures: Array, Structure, Queue, Adjacency Matrix.
- Algorithms: Dijkstra, Kruskal, Prim, BFS, Bubble Sort.

## Input Format

The program reads graph data from `input.txt`.

```text
